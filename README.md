# moaon.kr 사이트

빌드 도구 없는 손 HTML. 이 폴더를 그대로 올리면 된다(GitHub Pages: CNAME = moaon.kr).

## 공고 올리는 법
1. `notice/_양식.html` 을 복사해 `notice/YYYY-MM-DD-영문짧은이름.html` 로 저장(예: 2027-03-31-balance-sheet.html).
2. 【제목】【게시일】【공고 기간】【본문】을 법인관리 창이 준 공고문으로 채운다.
3. `notice/index.html` 목록 맨 위에 한 줄 추가, 「아직 게시된 공고가 없습니다」 줄은 지운다.
4. 대표 승인 → 올리기 → 주소를 법인관리 인계에 적는다.

★ 올린 공고는 지우지 않는다. 고칠 일이 생기면 정정 공고를 새 글로.
