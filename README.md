## 공고 올리는 법

공고문·공고기간은 법인관리 창이 준다. 글자를 다듬지 않고 그대로 게시한다.

1. `notice/_양식.html` 을 복사해 `notice/YYYY-MM-DD-영문짧은이름.html` 로 저장한다(예: `2028-03-31-balance-sheet.html`).
2. 【제목】【YYYY-MM-DD】【본문】을 채운다. 첨부 PDF는 같은 폴더에 넣고 본문에 링크한다.
3. `notice/index.html` 의 `id="notices"` 안 맨 위에 한 건을 넣는다. 형식은 그 파일의 주석에 있다. `data-end` 에 공고기간 끝날을 적으면 기간이 지난 뒤 「지난 공고」로 저절로 내려간다. 첫 공고 때 「아직 게시된 공고가 없습니다」 줄을 지운다.
4. 대표 승인 → 올리기 → 열어서 확인 → 주소를 법인관리 인계에 적는다.
5. 게시한 날과 공고기간 끝난 날에 화면을 PDF로 저장해 법인관리 창에 넘긴다(보관 `70_법인관리/공고/`).

★ 한 번 올린 공고는 고치거나 지우지 않는다. 틀리면 「정정 공고」를 새 글로 올린다. 저장소 커밋 이력도 지우지 않는다.

## 단계가 바뀔 때 (법인관리 창이 알려 줌)

- 설립등기 끝: 화면의 `모아온(농업회사법인 설립 준비 중)` → `농업회사법인 모아온 주식회사`, `대표` → `대표이사`, 모아온 페이지 「시작한 농업입니다」 → 「시작한 농업회사입니다」, `notice/index.html` 머리를 문안의 「등기 후」 문장으로.
- 사업자등록·통신판매업 신고 끝: 모든 페이지 바닥글의 빈 `<span class="foot-opt"></span>` 에 문안대로 번호를 적는다. 비어 있으면 화면에 나오지 않는다.
